# BLOCK-GAME — patched starter build

Це обережно виправлена версія на основі наданого `BLOCK-GAME.zip`. Основні механіки залишено в `test.py`, щоб не зламати залежності великого монолітного файлу. Зображення перенесені до `assets/images/`, а завантажувач текстур шукає їх у новій папці та підтримує старі шляхи.

## Запуск у Windows / VS Code
1. Розпакуй архів у нову папку. Не перезаписуй оригінальну гру, поки не перевіриш цю копію.
2. Відкрий папку в VS Code.
3. У терміналі виконай:
   ```powershell
   py -m pip install -r requirements.txt
   ```
4. Запусти `run_game.py` кнопкою **Run Python File** або командою `py run_game.py`.

## Зміни в цій збірці
- Виправлено пошук текстур при запуску з VS Code та при збірці PyInstaller; додано пошук у `assets/images/`.
- Виправлено шлях до текстур ендерменів.
- Ендермени тепер орієнтуються на гравця, віддзеркалюють текстуру за напрямком і не видаляються лише через віддалення від гравця.
- Прибрано сканування всіх блоків для кристалів дракона з кожного кадру: список оновлюється раз на 0,5 секунди.
- Трохи прискорено рух та анімацію дракона; вогняні кулі запускаються ближче до передньої частини його моделі.
- Ріст рослин більше не залежить від того, чи перебувають вони на екрані.
- Додано `backups/test_original.py` для повернення до початкового файлу.

## Важливо
Це не повна реалізація всіх запитаних функцій. Повноцінні чанки з потоковою генерацією, реальна посадка дракона на чашу, повна переробка генерації Незеру, модульне розділення всіх систем і мережевий мультиплеєр (LAN/інтернет, сервер, чат, скіни) потребують окремої розробки й тестування. Вони не позначені як готові в цій збірці.

Світ зберігається у `savegame.json`. Перед тестуванням використовуй копію світу, бо формат збереження не змінювався, але помилки гри можуть пошкодити збереження.
